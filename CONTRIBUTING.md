# Contributing to the Operately website

This repository holds the operately.com marketing site and the help center
at `/help`. Contributions to the Operately product itself belong in the
product repositories under [github.com/operately](https://github.com/operately).

## Ways to contribute

- Report an issue.
- Fix a typo or a broken link.
- Improve a help page.
- Propose a site change (new page, landing page, design tweak, etc).

## Getting started

Requirements: Node.js 22.12.0 or later.

```
npm install
cp .dev.vars.example .dev.vars
npm run dev
```

The site is served at `localhost:4321`.

See [docs/README.md](docs/README.md) for the full development guide,
including the two-server setup (Astro + Wrangler) used in local development.

## Making a change

1. Branch from `main`.
2. Open a pull request against `main`.
3. Every branch gets a Cloudflare Pages preview. Check your change in the
   preview before you ask for review.
4. Merges to `main` deploy to production.

## Before opening a pull request

- Run `npm run build` and make sure it passes.
- If you changed styles, check both the main site and `/help`.
- Shrink new images before committing them, and use Astro's `<Image/>`
  component (see [docs/README.md](docs/README.md)).

## Content rules

- Help center pages: follow
  [docs/help-center/README.md](docs/help-center/README.md) and
  [.agents/skills/write-help-docs/SKILL.md](.agents/skills/write-help-docs/SKILL.md).
- Never edit `src/content/docs/help/api/` by hand. Those pages are
  autogenerated.
- Handbook pages: follow [docs/handbook/README.md](docs/handbook/README.md).
- Every new page needs a contextual link from an existing page's body, as
  described in `AGENTS.md`.
