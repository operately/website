Setting a project's start date helps you adjust timelines and ensure your project schedule aligns with current priorities and resource availability.

## How to edit the start date

<Steps>
1. Open the project page and go to the **Overview** tab
2. In the sidebar, find the **Start date** section
3. Click on the start date area (or current start date if one exists)
4. Choose a date type, then select the date
5. Click **Confirm** to save the change
</Steps>

## Date type options

The date picker offers four different granularities to match your project's timeline:

**Day** — For a specific start day. Choose a particular day when the project should begin.

**Month** — For broader timeframes. Useful when you need flexibility within a month.

**Quarter** — For strategic projects. Perfect for quarterly planning.

**Year** — For long-term work. Use for annual or multi-year initiatives.

## When to use each date type

**Use Day for:**
- A specific start day
- Projects that must begin on a particular date

**Use Month for:**
- Projects with some flexibility
- Work that can start anytime in a given month

**Use Quarter for:**
- Strategic projects
- Work that aligns with quarterly planning

**Use Year for:**
- Long-term initiatives
- Projects that start sometime in a given year

## When to change start dates

Consider updating a project's start date when:

- Team members or resources become available earlier or later
- Project urgency has changed based on business needs
- Prerequisites or blockers have been resolved or introduced
- Overall project schedule needs to be realigned

Keeping project start dates accurate ensures realistic scheduling and helps teams plan their work effectively across your organization.
