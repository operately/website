Connect Claude to Operately with a custom remote MCP connector. Operately Cloud uses `https://app.operately.com/mcp`; self-hosted installations use `https://YOUR_INSTANCE/mcp`.

## Connect Operately

<Steps>
1. In Operately, open your avatar menu → **MCP Connections** → **Connect a client** → **Claude** and copy the server URL.
2. In Claude, open **Customize** → **Connectors** (or go to [claude.ai/customize/connectors](https://claude.ai/customize/connectors)).
3. Click **+ Add**, then select **Add custom connector**.
4. Enter a name such as **Operately** and paste the server URL. Leave **Advanced settings** empty.
5. Click **Add**.
6. Click **Connect** and sign in to Operately. Review the company and permissions (choose **View only** for read-only access), then click **Authorize**.
</Steps>

## Use Operately in a conversation

Adding the connector does not turn it on automatically for every chat. To enable it in a conversation:

<Steps>
1. Click the **+** button in the lower left of the chat.
2. Choose **Connectors** and toggle **Operately** on.
</Steps>

Write actions usually require confirmation in Claude. Review the tool input carefully before approving changes.
