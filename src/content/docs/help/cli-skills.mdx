Operately publishes skills that help compatible agent tools understand how to work with the Operately CLI and common Operately workflows.

If you're setting up an agent from scratch, see [Get started as an agent](/help/get-started-as-an-agent) for where skills fit in the full install-to-authenticated flow.

The skills live in the [operately/skills](https://github.com/operately/skills) repository and are installed with the [skills package on npm](https://www.npmjs.com/package/skills).

## Install all Operately skills

```bash
npx skills add https://github.com/operately/skills
```

Or install only the Operately CLI skill:

```bash
npx skills add https://github.com/operately/skills --skill operately-cli
```

## What to install

- Install the whole repository if you want all Operately skills that are published there.
- Install `operately-cli` if you only need guidance for working with the Operately CLI.
