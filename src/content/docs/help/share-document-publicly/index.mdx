---
title: Share a document publicly
description: Create or revoke a public link to a published document.
---

import { Steps } from '@astrojs/starlight/components';

Public sharing lets anyone with the link read the latest version of a document and its attachments without signing in. Visitors cannot edit the document or comment on it.

Publish any [draft](/help/create-document#save-and-find-drafts) before sharing it publicly.

<Steps>
1. Open the published document.
2. Open the **...** menu and select **Share publicly**.
3. Click **Enable public sharing**.
4. Click **Copy public link** and send the link to your readers.
</Steps>

{/* Screenshot placeholder: ![Screenshot: Share publicly dialog with the public link and Disable public sharing button](./public-sharing.png) */}

[Edits to the document](/help/edit-document) appear at the same public link.

## Stop sharing

Open **...** → **Manage public sharing** → **Disable public sharing**. The link stops working immediately. Enabling sharing again creates a new link.

Deleting the document or its parent space, project, or goal also makes it unavailable.
