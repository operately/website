## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/project_templates/get_discussion` |
| Handler | `OperatelyWeb.Api.ProjectTemplates.GetDiscussion` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
