## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/project_templates/get` |
| Handler | `OperatelyWeb.Api.ProjectTemplates.Get` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
