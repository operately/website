## Endpoint

| Property | Value |
| --- | --- |
| Type | `mutation` |
| Method | `POST` |
| Path | `/api/external/v1/project_templates/update_task_assignees` |
| Handler | `OperatelyWeb.Api.ProjectTemplates.UpdateTaskAssignees` |

## Authentication

- Requires a valid API token.
- Requires a write-enabled token.
- Read-only tokens return `403`.
