## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/project_templates/list` |
| Handler | `OperatelyWeb.Api.ProjectTemplates.List` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
