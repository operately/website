## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/goals/count_children` |
| Handler | `OperatelyWeb.Api.Goals.CountChildren` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
