## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/documents/list_document_versions` |
| Handler | `OperatelyWeb.Api.Documents.ListVersions` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
