## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/kpis/get_kpi` |
| Handler | `OperatelyWeb.Api.Kpis.GetKpi` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
