## Endpoint

| Property | Value |
| --- | --- |
| Type | `mutation` |
| Method | `POST` |
| Path | `/api/external/v1/kpis/log_kpi_entry` |
| Handler | `OperatelyWeb.Api.Kpis.LogKpiEntry` |

## Authentication

- Requires a valid API token.
- Requires a write-enabled token.
- Read-only tokens return `403`.
