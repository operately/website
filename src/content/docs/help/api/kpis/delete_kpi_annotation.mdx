## Endpoint

| Property | Value |
| --- | --- |
| Type | `mutation` |
| Method | `POST` |
| Path | `/api/external/v1/kpis/delete_kpi_annotation` |
| Handler | `OperatelyWeb.Api.Kpis.DeleteKpiAnnotation` |

## Authentication

- Requires a valid API token.
- Requires a write-enabled token.
- Read-only tokens return `403`.
