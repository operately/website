## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/kpis/list_kpis` |
| Handler | `OperatelyWeb.Api.Kpis.ListKpis` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
