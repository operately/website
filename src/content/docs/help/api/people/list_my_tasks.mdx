## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/people/list_my_tasks` |
| Handler | `OperatelyWeb.Api.People.ListMyTasks` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.


## Inputs

This endpoint has no input fields.

## Outputs

| Field | Type | Required | Nullable |
| --- | --- | --- | --- |
| `tasks` | array of `task` object | Yes | No |
