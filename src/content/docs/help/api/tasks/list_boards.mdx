## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/tasks/list_boards` |
| Handler | `OperatelyWeb.Api.Tasks.ListBoards` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
