## Endpoint

| Property | Value |
| --- | --- |
| Type | `query` |
| Method | `GET` |
| Path | `/api/external/v1/companies/search` |
| Handler | `OperatelyWeb.Api.Companies.Search` |

## Authentication

- Requires a valid API token.
- Read-only and full-access tokens can execute this query.
