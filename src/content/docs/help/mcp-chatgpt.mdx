Connect ChatGPT to Operately as a custom MCP plugin. Operately Cloud uses `https://app.operately.com/mcp`; self-hosted installations use `https://YOUR_INSTANCE/mcp`.

## Connect Operately in ChatGPT

<Steps>
1. In Operately, open your avatar menu → **MCP Connections** → **Connect a client** → **ChatGPT** and copy the server URL.
2. In ChatGPT, select **Plugins** in the sidebar or go to [chatgpt.com/plugins](https://chatgpt.com/plugins).
3. Select **+**, then **Add custom MCP server**.
4. Enter a name such as **Operately**, paste the server URL, and choose **OAuth**.
5. Review the prompt and choose **Create as a plugin**.
6. Sign in to Operately, choose your company if prompted, review the permissions (choose **View only** for read-only access), and click **Authorize**.
7. Install the plugin.
</Steps>

## Use Operately in a conversation

<Steps>
1. Start a new chat in ChatGPT.
2. Type `@` and select **Operately**.
3. Ask a question or request an action—for example, *"Which of my tasks are open?"*
</Steps>

Write actions usually require confirmation in ChatGPT. Review the tool input carefully before approving changes.

Your workspace permissions apply to every request. Check granted access anytime under **MCP Connections** → **Connected Clients**.
