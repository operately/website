Create folders to organize the content in your space.

To create a folder:

<Steps>
1. Open the space where you want to create the folder.
2. Open the Resource Hub where you want the folder.
3. Click the **Add** button in the top left corner.
4. Select **New Folder**.
5. Give your folder a name.
6. Click **Save** to create the folder.
</Steps>

With Edit access to the space, you can organize a hub into folders. Folders can contain documents, files, links, and other folders.
