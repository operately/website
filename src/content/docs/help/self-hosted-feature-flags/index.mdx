---
title: Manage experimental features
description: Turn experimental features on or off for a company as an installation administrator.
---

import { Steps } from '@astrojs/starlight/components';

Site administrators can enable experimental features for individual companies. Company administrator access alone does not grant access to the **Admin Panel**.

<Steps>
1. On the company-selection screen, open **Admin Panel**.
2. Select **All Companies** or **Active Companies**, then open the company.
3. Find **Feature flags** and turn the available features on or off.
</Steps>

{/* Screenshot placeholder: ![Screenshot: Company administration page with Feature flags toggles](./feature-flags.png) */}

Each change applies only to that company. Available features depend on your installation's version.

See [Update your installation](/help/self-hosted-update) for upgrading Operately.
