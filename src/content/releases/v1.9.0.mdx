Operately v1.9 is here. Recurring projects can start from a template. Search now looks inside documents and discussions, not just titles. And published docs keep a history you can compare and restore.

## Project templates: Start recurring work from a proven structure

If you run the same kind of project more than once, you can save the structure as a template. Creating a project from it copies milestones, tasks, people, discussions, and Docs & Files into a new project that stands on its own.

You can also turn an existing project into a template when you already have one that works well. Later edits to the template do not change projects you already created from it.

See [Project templates](/help/project-templates) and [Save a project as a template](/help/save-project-as-template).

<BigImage src={projectTemplates} alt="Project Overview Actions menu with Save as template highlighted" />

## Full-text search: Find work by title and content

Quick search still finds work by title and name, and it now includes discussions and Docs & Files. When you need to look inside the writing itself, a dedicated Search page looks through titles and content.

That page also finds closed, completed, archived, and paused work, so older decisions stay findable.

The full walkthrough is in [Global Search](/help/global-search).

<BigImage src={fullTextSearch} alt="Search page with filters and results for titles and content" />

## Document version history: Compare and restore published docs

Published documents now keep a history of title and content changes. You can open that history, compare two versions side by side, and restore an earlier one if you need to.

Restoring writes a new current version. Older versions stay in the list, so nothing is thrown away.

Details are in [View document version history](/help/document-version-history).

<BigImage src={documentVersionHistory} alt="History of changes timeline with See what changed on a document version" />

## Additional improvements

This release includes a number of smaller improvements that make day-to-day work more reliable:

**Shared List and Board view**: If you can edit a project, your **List** or **Board** choice on the Tasks tab is saved for the team.

**Contributors on Overview**: Manage the project team from the Overview sidebar instead of separate pages.

**Complete milestones with open tasks**: When a milestone still has open tasks, choose what to do with them before completing the milestone.

**Collapsed completed milestones**: Completed milestones stay on the project Tasks view, collapsed by default.

**Markdown shortcuts in the editor**: Type familiar Markdown shortcuts for bold, italic, lists, code, links, and more while writing.

**Assigned On in Your Tasks**: On the **Tasks** tab in **My work**, see when each task was assigned to you.

**Goal progress on Work Maps**: Hover a goal's progress bar to see **Targets** and **Checklist**.
